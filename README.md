# ganpatibappa-python-drawing
# Bhagwan Shree Ganesh - Step-by-Step Python Drawing 🕉️

An interactive, animated vector drawing of **Bhagwan Shree Ganesh** rendered in real-time on a pitch-black canvas using **Python & Pygame**.

---

## ✨ Features
- **Stroke-by-Stroke Animation**: Real-time vector drawing using Bézier curve interpolation.
- **10 Divine Steps**: From the radiant Prabhavali (Aura) and Golden Mukut to the sacred Modak bowl and Ekdanta.
- 🖥️ **Fullscreen Support**: Dynamic aspect-ratio auto-scaling for any monitor resolution (1080p, 2K, 4K).
- 🎮 **Interactive Keyboard Controls**:
  - `F11` / `F`: Toggle Fullscreen / Windowed Mode
  - `Space`: Skip current step (fast-forward)
  - `+` / `-`: Increase / Decrease drawing speed
  - `R`: Restart animation
  - `ESC`: Exit application

---

## 🚀 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/saicharan197/ganpatibappa-python-drawing
   cd ganpatibappa-python-drawing
   ```

2. **Create and activate a virtual environment:**
   ```bash
   # Windows
   python -m venv venv
   .\venv\Scripts\activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the project:**
   ```bash
   python ganesh.py
   ```
